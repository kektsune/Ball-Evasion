Ball Evasion is a Python-based mini-game created in Visual Studio Code, where the player controls a red circle and must avoid incoming moving circles for as long as possible.

Features
- Drag and drop player control
- Dynamic shape generation
- Object movement and animation
- Score tracking system
- Time survival tracking

IMPORTANT:
This project has been primarily tested on Windows. It may also work on macOS and Linux, but compatibility has not been fully verified.

This is the first release of Ball Evasion. Feedback, bug reports, and suggestions are welcome via the Issues tab.
